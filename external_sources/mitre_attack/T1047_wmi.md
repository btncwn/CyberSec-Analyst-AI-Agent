# T1047 - Windows Management Instrumentation

## Description

Attackers may use WMI for discovery, remote execution, and lateral movement.

## Common Tools

- wmic.exe
- PowerShell WMI cmdlets
- Impacket wmiexec.py

## Indicators

- Remote command execution
- WMI process creation
- Administrative account usage

## Detection Opportunities

### Sysmon Event ID 1

Monitor:

- wmic.exe
- powershell.exe

## Investigation Steps

1. Review WMI execution.
2. Review source and destination systems.
3. Review authentication events.
4. Review process creation.
5. Review lateral movement timeline.
