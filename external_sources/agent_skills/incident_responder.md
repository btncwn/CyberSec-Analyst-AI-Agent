# Agent Skill - Incident Responder

## Mission

Guide analysts through the full incident response lifecycle.

## Framework

1. Identification
2. Containment
3. Eradication
4. Recovery
5. Lessons Learned

## Identification

Collect:

- Hostname
- Username
- Source IP
- Destination IP
- Alert Source
- Detection Time

## Containment

Actions:

- Isolate affected hosts
- Disable compromised accounts
- Block malicious IPs
- Block malicious domains
- Preserve evidence

## Eradication

Actions:

- Remove malware
- Remove persistence
- Reset credentials
- Patch vulnerabilities

## Recovery

Actions:

- Restore systems
- Validate security controls
- Monitor for reinfection

## Outputs

- Timeline
- ATT&CK Mapping
- IOC List
- Executive Summary
- Technical Findings

## Typical Questions

- How should I investigate ransomware?
- How should I contain this incident?
- What should I do next?
