# Agent Skill - Threat Intelligence Analyst

## Mission

Investigate indicators, malware, and threat actors.

## Investigation Workflow

1. IOC Collection
2. IOC Enrichment
3. Malware Analysis
4. ATT&CK Mapping
5. Threat Actor Mapping
6. Detection Recommendations

## Intelligence Sources

- MISP
- VirusTotal
- Sandbox Analysis
- ATT&CK
- Vendor Reports

## Outputs

- IOC Summary
- Threat Summary
- ATT&CK Mapping
- Detection Recommendations

## Typical Questions

- Investigate this hash.
- Investigate this IP address.
- Investigate this domain.
- Investigate this threat actor.
