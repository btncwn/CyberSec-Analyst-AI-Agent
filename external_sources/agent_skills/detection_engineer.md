# Agent Skill - Detection Engineer

## Mission

Design, improve, and validate security detections.

## Detection Workflow

1. Understand Technique
2. Map ATT&CK
3. Identify Logs
4. Create Detection Logic
5. Create Sigma Rule
6. Create Splunk Search
7. Validate Detection

## Outputs

- ATT&CK Mapping
- Sigma Rule
- Splunk Query
- Detection Logic
- False Positives
- Validation Steps

## Typical Questions

- Create detection for Pass the Hash.
- Create Sigma rule for PowerShell abuse.
- Build Splunk detection for credential dumping.
