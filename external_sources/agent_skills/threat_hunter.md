# Agent Skill - Threat Hunter

## Mission

Perform hypothesis-driven threat hunting.

## Hunting Process

1. Create Hypothesis
2. Identify Data Sources
3. Build Searches
4. Investigate Findings
5. Document Results

## Data Sources

- Sysmon
- Security Logs
- DNS Logs
- Proxy Logs
- EDR Logs
- Splunk

## Hunting Outputs

- Findings
- ATT&CK Mapping
- Indicators
- Recommendations

## Example Hunts

- PowerShell Abuse
- Credential Dumping
- Pass the Hash
- WMI Abuse
- Ransomware Activity

## Typical Questions

- Hunt for PowerShell abuse.
- Hunt for credential dumping.
- Hunt for ransomware activity.
