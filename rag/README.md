# Retrieval-Augmented Generation (RAG)

## Purpose

This directory contains the Retrieval-Augmented Generation (RAG) components for CyberSec Analyst AI Agent v2.0.

The goal is to allow the AI assistant to retrieve trusted cybersecurity knowledge before generating responses.

## Benefits

- Reduces hallucinations
- Improves ATT&CK mapping
- Improves Sigma rule generation
- Improves Splunk query suggestions
- Improves incident response guidance
- Keeps sensitive data local

## Future Components

- Document ingestion
- Embedding generation
- ChromaDB vector storage
- Retrieval engine
- Context filtering
- Prompt injection defenses
